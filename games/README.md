# Games in this universe

Add yours with a one-line pull request. Any genre, any engine, any medium — this list is
not limited to text games and never was.

|---|---|---|

## Adding yours

Open a pull request adding a row. That is the entire process — see
[CONTRIBUTING.md](../CONTRIBUTING.md).

```
| **YOUR GAME** | one line about it | you | 
```

Link it however you like: a web build, an itch.io page, a repo, a PDF, a photograph of a
board game on a kitchen table. Finished and rough are both fine. Free and paid are both
fine.
